# Painel da Gestão · Organizador de Aulas

App separado da gestão pedagógica. Usa o mesmo Firebase do Organizador de Aulas (os professores continuam no diarioonline.vercel.app).

Depois de publicar na Vercel, adicione o novo domínio em Firebase → Authentication → Configurações → Domínios autorizados, senão o login com Google não funciona.
